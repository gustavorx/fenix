# Fenix Web

Frontend SPA do Fenix, construida com React, TypeScript e Vite.

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento local.
- `npm run build`: gera a build de producao e valida o TypeScript.
- `npm run lint`: executa a analise estatica com ESLint.
- `npm run preview`: abre uma visualizacao local da build de producao.
